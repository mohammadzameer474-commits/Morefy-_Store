MORE​FY APP – SHURUATI VERSION

Is folder mein Morefy ka basic installable website/PWA starter hai.

Abhi kya kaam karta hai:
- Mobile-friendly Morefy store page
- Demo fashion categories
- Har product par Order Now button
- Button WhatsApp par aapke number 8983909313 ko message kholta hai
- HTTPS hosting par PWA install support aur basic offline cache

ZAROORI:
- Product cards abhi demo hain; inhe asli product photos, naam aur prices se replace karna hoga.
- Dealer abhi nahi hai, isliye order filhaal aapke WhatsApp par aayega.
- Dealer milne par app.js mein ORDER_WHATSAPP number badalna hoga.
- Number code mein dikhai dega aur customer WhatsApp par aapko message kar sakega.
- Is starter mein payment gateway, inventory, admin panel, automatic dealer fulfilment ya Play Store APK nahi hai.

MOBILE SE PUBLISH:
1. ZIP extract karein.
2. GitHub par account banayein/login karein.
3. New public repository banayein, naam: morefy-store
4. Is folder ki files repository ke root mein upload karein.
5. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
6. GitHub Pages ka HTTPS link milne ke baad Android Chrome mein kholein.
7. Chrome menu (⋮) > Add to Home screen / Install app.

Baad mein badlav:
- WhatsApp number: app.js mein ORDER_WHATSAPP
- Products: app.js mein products array
- Design: style.css
